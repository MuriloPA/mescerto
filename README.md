# MêsCerto

Aplicativo de controle financeiro pessoal, feito em Flutter, com banco de dados PostgreSQL no Supabase.

## Funcionalidades

- Cadastro e login
- Saldo, entradas, saídas e limite mensal
- Lançamentos de receitas e despesas, com extrato e filtro por mês
- Gastos por categoria
- Metas de economia
- Assinaturas e alertas
- Tema claro e escuro

## Tecnologias

- Flutter
- PostgreSQL
- Supabase (banco de dados, login e API)

## Banco de dados

Seis tabelas: perfis, categorias, lançamentos, limites mensais, metas de economia e assinaturas. Cada usuário só acessa os próprios dados.
